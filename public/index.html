WHAT THIS APP DOES

Run automated WhatsApp replies across multiple authorized accounts.

MoE Bot connects each WhatsApp account through a QR/pairing step, listens for incoming messages, applies the reply mode you choose, sends the configured response, and records every connection event and failure so you can act quickly.

01 / CONNECTAdd a node and authorize it from WhatsApp Linked Devices.
02 / CONFIGUREChoose command-only, reply-to-all, or log-only mode.
03 / OPERATEWatch messages, replies, status and reconnect events live.
04 / IMPROVEReview logs and tune the response without touching code.
